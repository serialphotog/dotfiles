# Adam Thompson's Dotfiles

My current dotfiles used across MacOS and Linux.

# Setup on a New Machine

1. [Install Chezmoi](https://www.chezmoi.io/install/). 
2. Apply with `chezmoi init --apply https://github.com/serialphotog/dotfiles.git`

You can update them with `chezmoi update` and apply with `chezmoi -v apply`.
